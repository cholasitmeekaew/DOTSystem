# dot-system

[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-cwekxkds)

## Development

Requires Node.js 22.12 or newer and pnpm 11.24.0.

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

## Checks

```bash
pnpm lint
pnpm typecheck
pnpm build
```
